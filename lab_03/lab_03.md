## Краткие теоретические сведения
* **Модуль в Python** — это отдельный файл с расширением `.py`, содержащий определения функций, переменных и классов, обеспечивающий повторное использование кода.
* **Импорт:** Форма `from module import function` позволяет подключать конкретные функции из пользовательских или системных модулей напрямую в текущее пространство имен.
* **Точка входа `if __name__ == '__main__'`** применяется для отделения основного исполняемого кода скрипта от логики функций при его импорте другими модулями.
* **Списки (`list`)** — упорядоченные динамические изменяемые массивы элементов произвольных типов.
* **Срезы (`[start:stop:step]`)** позволяют извлекать фрагменты последовательностей, где `start` — начальный индекс (включительно), а `stop` — конечный индекс (не включительно).
* **Системный список `sys.argv`** хранит аргументы командной строки. Элемент `sys.argv[0]` всегда содержит имя запускаемого скрипта, а последующие индексы — переданные из консоли параметры.

## Задание
**Физический процесс / инженерное явление:** Главный энергетик предприятия анализирует суточный график электрической мощности (24 часа). Потребление разбивается на 3 смены (утренняя, дневная, ночная) для оценки пиковых нагрузок и оптимизации двухставочного тарифа.

**Задачи модуля (`mod_variant.py`):**
1. `calculate_shift_consumption(hourly_power)` — разбивает 24-часовой список срезами на 3 смены `[0:8]`, `[8:16]`, `[16:24]` и считает расход по сменам;
2. `get_peak_hours(hourly_power, peak_level)` — возвращает список часов, когда мощность превышала установленный лимит.

## Исходный код программы

### Пользовательский модуль `mod_variant.py`
```python
def calculate_shift_consumption(hourly_power):
    # Считает расход электроэнергии суммарно по трем 8-часовым сменам.
    return sum(hourly_power[0:8]), sum(hourly_power[8:16]), sum(hourly_power[16:24])

def get_peak_hours(hourly_power, peak_level):
    # Возвращает список часов, когда мощность превышала лимит.
    return [hr for hr, pwr in enumerate(hourly_power) if pwr > peak_level]
```

### Главный исполняемый скрипт `main.py`
```python
import sys
from mod_variant import calculate_shift_consumption, get_peak_hours

def main():
    # Чтение лимита из консоли.
    if len(sys.argv) > 1:
        peak_limit = float(sys.argv[1])
    
    # Исходный суточный профиль потребления (24 часа)
    hourly_power = [
        150, 140, 130, 140, 160, 200, 350, 420,
        450, 480, 460, 430, 410, 440, 470, 490,
        420, 380, 300, 250, 210, 180, 160, 150
    ]
    # Расчет и вывод результатов
    s1, s2, s3 = calculate_shift_consumption(hourly_power)
    
    print("=== АУДИТ ЭЛЕКТРОПОТРЕБЛЕНИЯ ===")
    print("Потребление по сменам:")
    print(f"  - Смена 1 (Ночь): {s1} кВт*ч")
    print(f"  - Смена 2 (День): {s2} кВт*ч")
    print(f"  - Смена 3 (Вечер): {s3} кВт*ч")
    
    # Считаем пиковые часы в отдельную переменную
    peaks = get_peak_hours(hourly_power, peak_limit)
    print(f"Пиковые часы (>{int(peak_limit)} кВт): {peaks}")

if __name__ == '__main__':
    main()
```
