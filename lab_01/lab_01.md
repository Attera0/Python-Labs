## 2. Краткие теоретические сведения
Язык Python использует динамическую типизацию, что означает автоматическое связывание типа данных с переменной в момент присваивания значения.

Функция `input()` служит для ввода данных с клавиатуры в виде строки. Для выполнения математических операций строки преобразуются к числовым типам, например, с помощью функции `float()` для вещественных чисел.

Форматирование строк (f-строки) в Python позволяет лаконично выводить переменные и управлять их отображением. Спецификатор `:.4f` округляет вещественную часть числа до 4 знаков после запятой.

В данной работе производится расчет объема цилиндра по формуле: 
V = Pi * r^2 * h

## 3. Исходный код программы
```python
# Константа числа Пи для выполнения геометрических расчетов
Pi = 3.14159

# Запрос у пользователя значения радиуса через консоль.
# Функция input() считывает текст, а float() преобразует его в вещественное число.
r = float(input("введите радиус: "))

# Запрос у пользователя значения высоты через консоль
h = float(input("Введите высоту: "))

# Расчет объема цилиндра по физической формуле
V = Pi * (r ** 2) * h

# Вывод результата с округлением вещественной части до 4 знаков после запятой методом .format()
print("{:.4f}".format(V))
```
